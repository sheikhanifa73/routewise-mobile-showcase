Interview answer

How do you handle API failure?

“I separate temporary network failure, expired sessions and validation errors. The repository maps typed errors; the view model updates UI state; safe requests retry with backoff; and the user gets a useful recovery action.”

How do you protect customer data?

“Use Keychain for tokens, TLS, server-side authorisation, minimal logging, focused permissions and a tokenising payment provider. Never store secrets or card details in the app.”
